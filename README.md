# FaBoOne

台股公司分析 PWA。目標是讓使用者在一頁中掌握公司的成長、獲利、財務體質與估值變化。

## MVP 範圍

- 以 `2330 台積電` 做為第一個完整案例。
- 查詢公司基本資料、日收盤價與月營收。
- 顯示近 8 季營收、EPS 與自由現金流趨勢。
- 顯示可追溯來源的規則式分析摘要。

第一版不包含美股、即時行情、新聞爬蟲、登入與推播。
