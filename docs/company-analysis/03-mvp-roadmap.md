# MVP 路線圖

## 驗證標的

第一個完整案例：`2330 台積電`。先驗證一家公司、再擴展到 10 家、最後才擴展全市場。

## 開發順序

1. **靜態介面**：完成手機優先的公司分析頁，使用 mock data。
2. **資料模型與 API**：建立 Company、PriceDaily、RevenueMonthly、FinancialQuarterly、CashFlowQuarterly。
3. **價格與月營收匯入**：建立可重跑的擷取程序、資料驗證與更新紀錄。
4. **季報與現金流匯入**：新增財報標準化與衍生指標計算。
5. **分析規則**：輸出可解釋的文字結論，例如「營收連續三季年增」或「自由現金流較去年同期轉弱」。
6. **搜尋與擴大公司範圍**：先加入 10 家公司，再評估全市場匯入。

## 每個階段的完成定義

| 階段 | 完成標準 |
| --- | --- |
| 靜態介面 | 手機可讀、四大面向與圖表呈現合理 |
| 資料匯入 | 可重跑、可追溯來源、失敗時有紀錄 |
| 公司頁 | 2330 各資料有期間、來源、更新時間 |
| 擴大範圍 | 10 家不同產業公司均能正常顯示 |

## 延後項目

新聞、美股、即時行情、推播與登入，都在台股公司頁資料正確且易讀後再安排。
