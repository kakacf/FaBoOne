## 文件導覽

- [產品範圍](01-product-scope.md)：產品目的、使用者情境與不做事項。
- [資料字典](02-data-dictionary.md)：首版資料欄位、計算規則與資料來源原則。
- [MVP 路線圖](03-mvp-roadmap.md)：以 2330 台積電為驗證案例的開發順序。

## 第一個驗收目標

輸入 `2330` 後，使用者能在公司頁看見收盤價、月營收、近 8 季營收與 EPS、自由現金流，且每個資料區塊都標示資料期間、來源與更新時間。
