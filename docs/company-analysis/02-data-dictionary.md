# 資料字典與口徑

## 基本原則

- 所有金額必須存放原始數值、幣別與單位；介面可依公司報表單位格式化。
- 衍生指標須保留計算公式與使用的原始欄位。
- 每筆或每組資料都記錄來源網址、公告/交易日期與擷取時間。
- 財報以合併報表優先；更正或重編的申報資料應可覆寫並保留版本紀錄。

## 首版實體

| 實體 | 必要欄位 |
| --- | --- |
| Company | ticker、名稱、上市別、產業、資料來源識別碼 |
| PriceDaily | ticker、交易日、收盤價、成交量、來源、擷取時間 |
| RevenueMonthly | ticker、年月、當月營收、去年同期營收、月營收 YoY、來源、公告日 |
| FinancialQuarterly | ticker、會計年度、季度、營收、EPS、毛利率、營業利益率、淨利率、來源 |
| CashFlowQuarterly | ticker、會計年度、季度、營業現金流、資本支出、自由現金流、來源 |

## 衍生指標

| 指標 | 計算方式 |
| --- | --- |
| 月營收 YoY | (本月營收 / 去年同月營收 - 1) × 100% |
| 季營收 YoY | (本季營收 / 去年同季營收 - 1) × 100% |
| 季營收 QoQ | (本季營收 / 上季營收 - 1) × 100% |
| 自由現金流 FCF | 營業活動現金流量 - 資本支出 |
| 負債比 | 總負債 / 總資產 |

## 資料來源策略

第一版只使用官方公開資料。價格與上市公司基本資料可由 TWSE OpenAPI 取得；月營收與財務報表以交易所/公開資訊觀測站公開資料為準。後端排程抓取後寫入資料庫，前端只能讀取本系統 API，不能直接呼叫外部資料源。

> 待確認：上櫃公司的資料來源與欄位映射在台股上市流程穩定後再納入。
